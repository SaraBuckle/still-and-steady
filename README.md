# Still & Steady

Free mobile-first Bible-based encouragement for adults and families, with a parent-guided Little Hearts experience.

## Live website
https://sarabuckle.github.io/still-and-steady/

## Features
- Two experiences: adults and parent-guided children
- Feeling-based Scripture and prayers
- Seven-day journey and device-local favourites
- Optional browser text-to-speech reflections
- Situation-based encouragement and bedtime reflection
- Downloadable square Scripture cards and Pinterest sharing entry point
- Search metadata, sitemap, robots and privacy page

## Architecture
Plain HTML, CSS and JavaScript, deployed through GitHub Pages. No paid API or account required. No personal information submitted. Saved passages stay in localStorage.

## Editorial and safety notes
Scripture quotes use the public-domain King James Version. Review quotations and references before broader promotion. Content is faith-based encouragement, not clinical advice. Little Hearts is designed for adult guidance. Browser speech voices and Pinterest sharing capabilities vary by platform.

## Known limitations
No scheduled notifications, recorded audio, unrestricted AI chat, analytics, or automatic social publishing. Pinterest's pin builder may require a user to upload the downloaded card. Automated and cross-device testing remain to be done.
